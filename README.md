# Notavia APP

**Notavia** - это мобильное приложение для создания и организации заметок с поддержкой тегов, категорий, приоритетов, дедлайнов и чек-листов. Приложение работает без интернета, все данные хранятся локально на устройстве пользователя.

## Возможности
- Создание заметок
- Редактирование заметок
- Удаление заметок
- Поиск по названию и тегам
- Закрепление заметок
- Светлая и темная тема
- Авто-сейв заметок
- Счётчик символов и слов
- Чек-листы
- Категории заметок
- Метки приоритета
- Дедлайн заметок
- Сортировка и фильтры

## Технологии
- **Kotlin**
- **Android Studio**
- **Room SQLite**
- **DataStore**
- **Gradle**

## Требования
- **JDK 11+**
- **Android SDK 36**
- **Android 7.0 Nougat**
